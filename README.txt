MediKiosk Web Application
=========================

MediKiosk is a simple health assistance web application.

It allows users to ask health-related questions using
text input, voice input, and file upload.


Project Files
=============

1. index.html

This file contains the main structure of the website.

It includes:

- MediKiosk logo
- Home button
- About button
- Contact Us button
- Microphone button
- Question input box
- Send button
- Upload button
- About section
- Contact section
- Footer


2. style.css

This file contains the design of the website.

It controls:

- Website layout
- Colors
- Fonts
- Buttons
- Navigation
- Microphone design
- Upload button
- Question box
- Animations
- Mobile responsive design
- Footer


3. script.js

This file contains the functionality of the website.

It handles:

- Navigation between pages
- Sending questions
- Enter key for sending questions
- Voice recognition
- Microphone animation
- File selection
- Upload button


4. README.txt

This file contains information about the project
and instructions for running it.


How to Run the Project
======================

Step 1:
Install Visual Studio Code.

Step 2:
Open the "medikiosk-web" folder in Visual Studio Code.

Step 3:
Open the "index.html" file.

Step 4:
Install the "Live Server" extension in Visual Studio Code.

Step 5:
Right-click on "index.html".

Step 6:
Select "Open with Live Server".

Step 7:
The MediKiosk website will open in your browser.


Main Features
=============

1. Voice Input

Users can click the microphone button and speak
their health-related question.

The browser converts the speech into text.


2. Text Input

Users can type their question inside the
question box and press the send button.

The Enter key can also be used to send a question.


3. File Upload

Users can click the Upload button and select
a file from their device.

Currently, the selected file is only displayed
as a confirmation.

Actual file processing can be added later.


4. Navigation

The website contains three main sections:

Home
About
Contact Us


5. Responsive Design

The website works on both desktop and mobile
screen sizes.


Current Version
===============

This version is mainly the frontend of the
MediKiosk application.

The AI backend has not been connected yet.

Currently, when a question is submitted,
the website displays a temporary response.

Important Security Note
=======================

Do not put private API keys inside:

index.html
style.css
script.js

API keys should be stored safely on the
backend server.
